| 2026-11-06 | Geo policy for extracted claims: an explicit place hint that does not resolve inside the region means the fact is about somewhere else; benchmark-tagged sources map it to `country:US`, everything else is dropped (`geo_out_of_region`). | 2026-11-06 | Reconcile text rules: claims from the same document never contest (distinct facets); near-identical wording across outlets (token Jaccard >= 0.5) corroborates; free-text values over six words are distinct facts, not contradictions; a new claim for an earlier period than an open-ended existing one is superseded by it. `conflicts recheck` re-decides open conflicts after a rules change. | 32 initial conflicts were mostly monthly figures out of order and facets of one document; 14 genuine ones remain open. |

| 2026-11-06 | Falsifiers take an optional `period` (YYYY-MM, migration 0008): only that period's point is tested, so a same-month-next-year test on a seasonal series can be written; without it the latest point is tested on every run. The validator requires the period to be unobserved and on or before `by_date`. | Every second-round critic asked for year-on-year tests on rents, sales, lodging and sales tax; the analysts could not express them and said so. The overseer set the periods the analysts named in their descriptions on the round-two proposals before the second critic round. |
| 2026-11-06 | A review whose analyst proposal is identical to the current version stops at the gate with `unchanged` and writes nothing; re-running `theses review --force` is idempotent. | Found while re-running reviews in session mode. |
| 2026-11-06 | `llm carry-forward` is round-aware: it only reuses an answer whose request preamble matches (the critic's edits for the analyst; the proposal, ignoring null fields and periods, for the critic). | A schema change had drifted every request id; the earlier matcher could have handed a round-two answer to a round-one request. |
